# Published with a fresh single-commit history; internal docs live outside the repo

This repo was developed with a spec and implementation plan that reference private fundraising context. Because git history is published along with the tree — and this repo's audience is investors mid-diligence — we published from a fresh `git init` whose first commit is the finished packet, and the internal spec/plan documents live outside the repo entirely. That's why history starts at "Fulcra dealflow memory skill packet" rather than showing development.

**Consequences**: development provenance before publication is not publicly recoverable (deliberate); internal planning documents must never be committed here, even under `docs/` — there is no private area in a public repo.
